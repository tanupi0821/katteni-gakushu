無料タイピング練習ゲーム

ローマ字入力の練習ができるブラウザゲーム。インストールも登録も不要です。

クリックしてはじめる 日本語入力（IME）は OFF にしてください
操作中は Esc で設定・L で記録／枠の外をクリックで解除

どんなゲームか

右から流れてくる語句を、表示されたローマ字で打ち込んで撃ち落とします。 打ち間違えるとコンボが切れ、左のコアに触れられると体力が減ります。 1 回およそ 3〜6 分で終わるので、練習の合間に区切りよく遊べます。

日本語モードでは、敵ごとに 漢字・読み・打つローマ字の三段が出ます。 読めない漢字でも読みが見えるので、漢字の勉強で手が止まることはありません。 英語モードに切り替えると英単語のタイピング練習になります。

ふつうのタイピングゲームと違うところ

多くのタイピングゲームは「何文字打てたか」しか返しません。 このゲームは打鍵を 1 つずつ記録して、どのかなで指が止まっているかを出します。

結果画面の「指が止まったところ」は、他人ではなく自分の平均と比べた数字です。 1.00 が自分の平均で、1.80 と出ていればそのかなだけ 1.8 倍の時間がかかっている、という意味になります。 速い人にも苦手なかなはあるので、他人と比べても練習の役には立ちません。

打鍵数で割ってあるので、きょ（3 打鍵）が こ（2 打鍵）より 時間がかかること自体は苦手と判定されません。3 秒を超えて手が止まった分は、 考えていた時間とみなして数えていません。

ローマ字入力でつまずきやすいところ

練習していて指が止まるのは、たいてい次の 3 つです。 このゲームはどの打ち方でも正解にしますので、 ふだん使っている打ち方のままで構いません。

拗音（ようおん）— きゃ・しゅ・ちょ

ここが最も差が出ます。2 文字で 1 つの音なので、指が一瞬迷います。

かな打ち方（どれでも可）例
しゃsya / sha / sixya写真 → syasinn
ちょtyo / cho / cyo調子 → tyousi
じゅzyu / ju / jyu呪文 → jumonn
きょkyo / kilyo京都 → kyouto

促音（そくおん）— 小さい「っ」

次に来る音の子音を重ねます。xtu と打っても通りますが、重ねたほうが速いです。

語打ち方注意
がっこうgakkou / gaxtukouk を重ねる
いっしょissyo / isshos を重ねる
いっちicchi / ittiち の綴りで重ねる字が変わる

撥音（はつおん）— 「ん」の n と nn

後ろに来る音で変わります。ここを間違えると、打てているのに弾かれた感じがします。

語打ち方なぜ
しんぶんsinbunn後ろが子音なので n ひとつで進める。語末は nn
れんあいrennai後ろが母音。n ひとつだと「な」になってしまう
しんやsinnya後ろが y のときも nn が必要
こんにちはkonnnitiha後ろが n。n が 3 つ並ぶ

遊び方

  • タイトル画面で 1 = 英語 / 2 = 日本語ローマ字 を選ぶ
  • Enter ではじめる
  • 語句を打ち切ると撃破。同じ文字で始まる語が並んでいても、打ち進めれば絞り込まれる
  • ウェーブを越えるたびに強化を 1 つ選ぶ
  • Esc で一時停止と音量設定、L で自己ベストの記録

よくある質問

「し」は si と shi のどちらで打てばいいですか

どちらでも通ります。si / shi / ci のいずれでも受け付けます。ふだんの打ち方のままで構いません。

記録はどこに保存されますか

お使いの端末の中（ブラウザの localStorage）だけです。サーバーへは送っていません。ブラウザのデータを消すと記録も消えます。

スマートフォンで遊べますか

物理キーボードが必要なので、パソコンでの利用を想定しています。タブレットでも外付けキーボードがあれば遊べます。

日本語入力が ON のままだと打てません

ローマ字を直接受け取る作りなので、IME が ON だと変換窓に文字を取られます。半角/全角 キーで OFF にしてください。
