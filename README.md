# 勝手に学習計画 — 公開サイト

アプリ「勝手に学習計画」の紹介ページとプライバシーポリシーを置くリポジトリ。
GitHub Pages で公開する。

- `index.html` — 紹介ページ(App Store の「サポートURL」に登録する)
- `privacy-policy.html` — プライバシーポリシー(App Store / Google Play の必須項目)
- `icon.png` — アプリアイコン(512x512)

アプリ本体のソースは別の非公開リポジトリ (`study-timetable`) にある。
プライバシーポリシーの本文はそちらの `docs/privacy_policy.html` が元で、
内容を直したときは両方に反映すること。

## 公開の設定

リポジトリの Settings → Pages → Build and deployment で
「Deploy from a branch」、ブランチ `main` / フォルダ `/ (root)` を選ぶ。
